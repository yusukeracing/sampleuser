# Web制作ポートフォリオ「余白と、設計。」

ポートフォリオ本体と、独立して閲覧・操作できる3種類の自主制作デモです。既存の選手サイトをこのポートフォリオへ置き換えました。旧ファイルのバックアップは `/workspace/sampleuser-before-replacement.tar.gz` に保存しています。GitHub Pages用の配信設定を追加しています。公開にはリポジトリのSettings → PagesでSourceをGitHub Actionsに設定します。

## ローカル起動

Python 3があれば追加インストール・ビルドは不要です。

```sh
cd /workspace/sampleuser
python3 -m http.server 8100 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8100/` を開きます。停止は起動した端末で Ctrl+C。ポート使用中なら8101などへ変更してください。

| ページ | パス | 操作 |
|---|---|---|
| ポートフォリオ | `/index.html` | 料金・範囲の確認、制作例への移動、FAQ、相談案内 |
| カフェ「喫茶 こもれび」 | `/demos/cafe.html` | メニューの絞り込み、アクセス概念図、予約デモ案内 |
| 工務店「木と日々の工務店」 | `/demos/builder.html` | 施工例の絞り込み、入力確認、デモ完了時の入力消去 |
| 選手「REN AOI」 | `/demos/athlete.html` | 活動報告の絞り込み、応援・SNSデモ案内 |

HTMLのダブルクリックではなくHTTP経由でご覧ください。開発サーバーのURLはローカル閲覧用で、公開用リンクではありません。

## 更新する場所

- **ココナラURL**: `assets/config.js` の `coconalaUrl` だけを変更すると、本体の相談ボタンすべてに反映。HTTPSの `coconala.com` または `www.coconala.com` の出品URLを指定します。空欄・不正なURLはローカルの相談準備案内を表示します。
- **文章・メニュー・価格・施工例・戦績**: 各HTML内の該当セクションに集約。実在の情報へ変更する場合は権利と事実を確認してください。価格などはデモの架空設定です。
- **画像**: `assets/cafe.webp`, `house.webp`, `runner.webp`, `food.webp`。HTMLの`alt`も合わせて更新。差し替える画像の縦横比に応じてwidth/height、CSSのobject-positionを確認してください。
- **色・余白・画面幅ごとの調整**: `assets/style.css`。テーマ別の `.cafe`, `.builder`, `.athlete` を使用。
- **動作**: `assets/main.js`。デモ用の確認処理はテキストとして描画し、HTMLとして挿入しません。
- **制作画面プレビュー**: `assets/preview-cafe.webp`, `preview-builder.webp`, `preview-athlete.webp` は、今回実装した各デモの実際のPC画面キャプチャです。デモのファーストビューを変えたら、1440px幅で撮り直して更新してください。

## 撮影

各URL末尾に `?capture=1` を付けるとアニメーション・トランジション・スムーズスクロールを停止します。画面上の撮影パネルはありません。通常時もコンテンツをスクロール演出で隠していません。`prefers-reduced-motion`にも対応しています。

推奨: PC **1440×1000**（出品画像へ切り出すなら1440×900も可）、スマートフォン **375×900**、タブレット **768×1024**。全体を見せる場合はフルページ撮影も利用できます。撮影前にメニューとダイアログを閉じ、フィルターを「すべて」に戻し、フォーカス表示を外すため余白をクリックしてください。「自主制作／架空サイト」の表記は残してください。

| サイト | おすすめ撮影箇所 |
|---|---|
| 本体 | ファーストビューの制作画面3種、制作例一覧、対応できること |
| カフェ | 余白とコーヒーのファーストビュー、料理写真とおしながき、店舗案内 |
| 工務店 | 木の住まいのファーストビュー、施工サンプル、入力確認画面 |
| 選手 | 写真と大胆な文字のファーストビュー、活動報告、戦績・スポンサー |

`screenshots/` に、375・768・1440px幅 × 全4ページのフルページPNGを保存しています。各画像は実際のChromium表示です。

## 検証と制限

詳細は [VALIDATION.md](VALIDATION.md)、素材の記録は [SOURCES.md](SOURCES.md) を参照。

問い合わせ・予約・SNS・応援はデモです。外部送信、データ保存、実予約、決済、CMS管理画面はありません。問い合わせ確認中のみ入力がDOMに残り、「デモを完了して入力を消去」でリセットされます。入力には架空の内容を使用してください。送信ボタンは設けていません。これらを実用化するにはサーバーやサービス連携が必要で、この静的サイト制作サービスの対象外です。

製作者本人の氏名・連絡先・受注実績・評価は設定していません。ユーザー提供の「現役エンジニア」と、下記の料金・制作方針を掲載しています。「余白と、設計。」はこの制作サンプルのタイトルです。

## 掲載しているサービス条件

ユーザーから提供された方針を、トップ・料金・FAQ・相談ダイアログに反映しています。

- 静的サイトの新規制作: ページ数に関係なく一律50,000円。
- 新規制作の受付は月1件、制作期間は1か月。着手日・納品日は事前に確認。
- 基本はココナラのチャットでやり取りし、実際に動く画面を確認しながら制作。
- 既存サイトの修正・機能追加: 10,000円から。内容を確認して見積もり。
- Web制作の学習者も歓迎。希望に応じてコードにコメントを添付。
- HTML・CSS・JavaScriptによる静的サイト。Pythonは静的ページの生成や制作時の作業に利用する説明で、Pythonアプリのホスティングは含みません。
- ログイン・データベース・CMS管理画面・決済・実予約・フォーム実送信などのサーバー処理は対象外。

料金の税込・税別、修正回数など、指定されていない契約条件は追加していません。条件変更時は `index.html` と `assets/main.js` の相談案内を一緒に更新してください。

## 実装した安全性への配慮

全ページのCSPでスクリプト・スタイルを同一サイトに限定し、不要な通信やフォーム送信を禁止しています。デモ入力は `textContent` / `createTextNode` で表示します。外部リンクは相談URLのHTTPS・ココナラのホスト名を確認して利用します。

これはすべての攻撃・改ざんの防止を保証するものではありません。GitHubアカウントや公開先の権限・認証設定、ホスティング側の保護も別途必要です。CSPのHTTPレスポンスヘッダー設定は静的HTMLのメタ設定とは別です。新しい外部スクリプト・API・フォーム連携を追加する場合は、CSPとサービスの対応範囲を再検討してください。

## GitHub Pages

`.github/workflows/pages.yml` がmainへのpushで公開ファイルだけを配信します。ドキュメント・テスト・撮影PNGは配信対象から除外しています。初回は Settings → Pages → Build and deployment → Source を GitHub Actions に設定してください。公開先の標準URLは https://yusukeracing.github.io/sampleuser/ です。

robots.txtはデモのため検索エンジンにクロールしないよう指示しています。アクセス制限ではないため、URLを知る人は閲覧できます。
